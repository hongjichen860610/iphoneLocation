# iPhone 定位模拟控制台

一个单文件、零第三方 Python 依赖的本地 Web 控制台，通过 `pymobiledevice3` 接管已连接的 iPhone 的定位，实现「设定虚拟位置」「恢复真实定位」「按路径播放移动轨迹」等操作。

服务只监听本机 `127.0.0.1`，所有操作都在本机完成。

## 主要功能

- **设定虚拟位置**：输入 WGS-84 经纬度，或点击地图拾取坐标，下发到已连接的 iPhone。
- **恢复真实定位**：结束模拟会话，设备回到真实位置。
- **地址搜索**：接入高德地图 Web 服务，按关键词搜索 POI，选中后自动把 GCJ-02 坐标转换为 WGS-84 填入。
- **路径播放**：在地图上依次添加途经点（2~200 个），选择速度后让设备沿轨迹移动。
- **历史记录**：成功下发的位置会记录到本地，最多保留 50 条，可点击回填坐标，也可单条删除。
- **状态面板**：实时显示 `pymobiledevice3` 是否就绪、设备信息、当前是否有接管会话、是否正在播放。

## 环境要求与依赖

- **macOS**（安装说明基于 Homebrew；代码中同时兼容 `Windows` 下的 `.exe` 可执行文件名）。
- **Python 3.7 及以上**（`location.py` 仅使用标准库中的 `http.server`、`subprocess` 等模块，无需 `pip install` 任何 Python 包）。
- **pymobiledevice3**（通过独立虚拟环境安装，用于与 iOS 设备通信；其自身的 Python 版本要求由 `pip` 在安装时解析）。
- **iPhone 侧**：设置 → 隐私与安全性 → 开发者模式 → 打开并重启；数据线连接后在手机上点「信任」。
- **iOS 17+** 无需 root，工具会自动回退到用户态隧道。
- 浏览器可访问外网：页面从 `unpkg.com` 加载 Leaflet 1.9.4，地图瓦片来自高德。

## 安装

一次性准备运行环境：

```bash
brew install python
python3 -m venv ~/.venv-pmd3
~/.venv-pmd3/bin/pip install -U pymobiledevice3
```

安装 `pymobiledevice3` 的虚拟环境与运行 `location.py` 的 Python 相互独立：本项目的 Python 版本只需满足 3.7 及以上，`pymobiledevice3` 的版本要求由 `pip` 自行解析。

程序查找 `pymobiledevice3` 的顺序：

1. `~/.venv-pmd3/bin/pymobiledevice3`
2. `~/.venv-pmd3/bin/pymobiledevice3.exe`
3. `PATH` 中的 `pymobiledevice3`

## 使用

```bash
python3 location.py
```

启动后会自动打开浏览器并访问 `http://127.0.0.1:8788`。可用参数：

| 参数 | 说明 |
| --- | --- |
| `--port <端口>` | 指定监听端口，默认 `8788` |
| `--no-open` | 启动后不自动打开浏览器 |

示例：

```bash
python3 location.py --port 9000 --no-open
```

界面操作流程：

1. 顶部状态标签变绿（设备已识别、会话已建立）后即可操作。
2. 在「目标坐标 · WGS-84」中填写经纬度，或点击地图拾取，然后点「设定位置」。
3. 点「恢复真实」结束模拟。
4. 需要移动轨迹时点「开启加点模式」，在地图上依次添加途经点，选择速度后点「开始播放」。
5. 点「清空路径」可移除已添加的途经点。

## 配置项说明

配置文件为仓库根目录的 `location_config.json`：

```json
{"amap_key": "你的高德 Web 服务 Key"}
```

| 字段 | 说明 |
| --- | --- |
| `amap_key` | 高德「Web 服务」类型 Key，用于地址搜索接口。留空则地址搜索不可用，其余功能不受影响。 |

- Key 的读取优先级：`location_config.json` 中的 `amap_key` → 环境变量 `AMAP_KEY`。
- Key 也可以在页面中「粘贴高德 Key」后点「保存」写入，服务端会直接改写 `location_config.json`（保留其他已有字段）。
- 地址搜索调用的是 `https://restapi.amap.com/v3/place/text`，一次最多返回 8 条结果。

### 数据文件

| 文件 | 说明 |
| --- | --- |
| `location_config.json` | 配置文件，保存 `amap_key`。文件不存在时按空配置处理。 |
| `location_history.json` | 历史记录，JSON 数组，最多 50 条。 |

`location_history.json` 中单条记录的结构：

```json
{"id": "2e5009dc", "lat": 23.055629, "lng": 113.110384, "at": "2026-11-16T11:19:44+08:00", "kind": "set"}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 8 位十六进制随机串，用于删除该条记录 |
| `lat` / `lng` | WGS-84 经纬度，保留 6 位小数 |
| `at` | 记录时间，本机时区的 ISO 8601 字符串 |
| `kind` | 来源类型：`set`（单点设定）或 `route`（路径播放，记录终点） |

同一坐标重复下发不会新增记录，只会更新时间并提到最前。写文件采用先写 `.tmp` 再替换的方式，避免中途失败损坏历史。

## HTTP 接口

页面通过以下本地接口与服务通信，除 `/` 返回 HTML 页面外，其余接口均返回 JSON（页面每 2.5 秒轮询一次 `/api/status`）。

| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| GET | `/` | - | 返回内置控制台页面 |
| GET | `/api/status` | - | 工具链、设备、会话、播放状态 |
| GET | `/api/history` | - | 返回全部历史记录 |
| GET | `/api/geocode` | `q` | 地址搜索，`q` 为关键词 |
| POST | `/api/location` | `lat`、`lng` | 设定虚拟位置，纬度 -90~90，经度 -180~180 |
| POST | `/api/clear` | - | 清除模拟，恢复真实定位 |
| POST | `/api/route` | `points`、`speed` | 路径播放，`points` 为 `[[lat, lng], ...]` |
| POST | `/api/history/delete` | `id` | 删除指定历史记录 |
| POST | `/api/config` | `amap_key` | 保存高德 Key |

`/api/route` 的约束：至少 2 个途经点，最多 200 个；`speed` 单位为 km/h，默认 15，超出范围会被限制在 1~300。

## 常见注意事项

- **本服务仅监听 `127.0.0.1`**，不对外提供访问，也不做任何身份校验，请勿自行改绑到公网地址。
- **会话必须保活**：`simulate-location set` / `play` 是常驻进程，只有该进程存活期间定位才被接管。脚本退出或点「恢复真实」时，会结束子进程并释放接管。
- **路径播放结束后**：进程仍常驻在终点（定位保持接管），界面上的「播放中」状态会在推算时长 + 3 秒后回到空闲，属正常现象。
- **坐标系区分**：设备需要 **WGS-84**；高德地图瓦片与搜索结果都是 **GCJ-02**。页面已内置双向转换，如果手工填写坐标请确认是 WGS-84，否则会有数百米偏移。
- **「未发现设备」**：确认已插线并信任、开发者模式已开启并重启；或让 iPhone 与 Mac 处于同一 Wi-Fi（会尝试无线连接）。
- **「未装 pymobiledevice3」**：按上文「安装」重新创建 `~/.venv-pmd3`；页面「先装运行环境」卡片会直接给出命令。
- **开发者模式 / 信任报错**：根据服务返回的提示在手机上开启开发者模式，或拔插数据线后重新点「信任」。
- **`location_config.json` 含明文 Key**：公开仓库前请清空该文件中的 `amap_key` 或将其加入 `.gitignore`，改用环境变量 `AMAP_KEY`；已泄露的 Key 请到高德控制台重置。
- **仅供学习与调试**，请在本人拥有或已获授权的设备上使用，并遵守当地法律法规。
